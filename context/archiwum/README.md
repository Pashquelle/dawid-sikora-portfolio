# Archiwum — materiały wycofane z użycia

**Nic w tym folderze nie jest źródłem prawdy. Nie buduj na tych plikach, nie cytuj z nich
tekstów i nie kopiuj stylów** — nawet jeśli wyglądają na aktualne i nawet jeśli są jedynym
miejscem, gdzie coś jest opisane. Jeśli czegoś brakuje w aktywnych plikach, zapytaj,
zamiast sięgać tutaj.

## Obowiązujące pliki

| Plik | Rola |
|---|---|
| `context/brand.md` | marka, osobowość, ton — źródło prawdy |
| `context/brief.md` | cele, grupa docelowa, ograniczenia |
| `context/reference.html` | kierunek wizualny („Panel danych”) |
| `context/sitemap.html` | architektura informacji |
| `context/wireframe-dawid-sikora.html` | obowiązujący wireframe: treść i struktura |

## Co leży w archiwum

### Odrzucone kierunki wizualne
- **`podglad-kierunkow.html`** — pierwsza iteracja, pięć art direction dla hero
  (01 Redakcja, **02 Panel danych**, 03 Zakreślacz, 04 Plakat, 05 Oddech).
  Wybrany kierunek 02 został wyciągnięty do `context/reference.html`.
- **`podglad-kierunkow-2.html`** — druga iteracja, pięć wariantów wewnątrz kierunku 02
  (A Kanon, B Szeryf w siatce, C Arkusz, D Lekki druk, E Karta katalogowa).
  Żaden nie został wybrany.

### Wycofane wireframe'y i podstrony
- **`wireframe-final.html`** — wcześniejsza wersja strony głównej, treść po polsku.
  Zastąpiona przez `wireframe-dawid-sikora.html`.
- **`wireframe-nowe-teksty.html`** — wariant tekstowy tej samej strony.
- **`about.html`** — wycofana podstrona „o mnie”.
- **`case-study.html`** — wycofany szablon case study.

## Uwaga na pułapkę

Archiwalne wireframe'y mają **inną treść hero i inny język** niż obowiązujący
`wireframe-dawid-sikora.html`. Jeśli kiedyś pojawi się rozbieżność w copy — wygrywa
plik aktywny, nie archiwalny.
