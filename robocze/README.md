# Robocze / odrzucone

Nic z tego folderu nie jest podłączone pod serwis i nic stąd nie jest źródłem
prawdy. Trzymamy to tylko po to, żeby móc wrócić po kawałek tekstu albo zajrzeć,
jak coś wyglądało wcześniej.

| Plik | Co to |
|---|---|
| `index-copy.html` | wcześniejsza kopia strony głównej, zamrożona |
| `index-stary.html` | poprzednia wersja strony głównej |
| `teksty-odlozone.md` | fragmenty tekstów wycięte ze strony |
| `podglad/` | zrzuty robocze z pracy nad sekcjami |

**Uwaga:** kopie HTML mają w środku ścieżki typu `assets/...` liczone od
korzenia projektu, a leżą o poziom niżej — otwarte stąd nie pokażą obrazków.
To nie usterka do naprawy, tylko konsekwencja tego, że są zamrożone.
