# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

**Dawid Sikora's UX/UI Design Portfolio** — A portfolio website showcasing UX/UI and Product Design work to attract recruiters, design leaders, and heads of design. The site emphasizes the design process and thinking, not just polished screenshots.

The project is structured as a course-based learning path, with each lesson building out new components and documents.

## Key Brand Principles

- **Personality type:** INTP (thinking-focused, intuitive, unconventional)
- **Design philosophy:** Systems-focused UX that serves both users and business goals; data-heavy projects are a specialty

## Getting Started

When working on this project:

1. **Read context files first** — Understand the brand and brief before making any design or copy decisions
2. **Maintain alignment** — All work (wireframes, design, copy, interactions) should reflect the brand personality and strategic goals

## Aktywne pliki kontekstu

Tylko te pliki są źródłem prawdy:

| Plik | Rola |
|---|---|
| `context/brand.md` | marka, osobowość, ton |
| `context/brief.md` | cele, grupa docelowa, ograniczenia |
| `context/reference.html` | kierunek wizualny |
| `context/sitemap.html` | architektura informacji |
| `context/wireframe-dawid-sikora.html` | obowiązujący wireframe: treść i struktura |
| `DESIGN.md` | system projektowy: tokeny kolorów, typografii, odstępów |

`context/styleguide.html` jest wizualnym podglądem systemu, nie źródłem prawdy. Przy
rozbieżności wygrywa `DESIGN.md`.

**`context/archiwum/` jest wycofane w całości. Nie czytaj stamtąd, nie cytuj i nie kopiuj
stylów ani tekstów** — dotyczy to wszystkiego, co w tym folderze leży teraz i co trafi tam
później. Archiwalne wireframe'y mają inną treść hero i inny język niż plik obowiązujący;
przy rozbieżności zawsze wygrywa plik aktywny. Jeśli czegoś brakuje w aktywnych plikach —
zapytaj, zamiast sięgać do archiwum.

## Zasady szczegółowe

Szczegółowe zasady pracy — kierunek wizualny, ton i język, ograniczenia wizualne, strony
referencyjne i assets — są w `.claude/rules/` i wczytują się automatycznie przy plikach,
których dotyczą.
